# WD2 Enhanced

DirectX 11 grafički mod za Watch Dogs 2, namenjen igranju van mreže.

[WD2 Enhanced 0.37](https://github.com/lukalazicsrb-eng/wd-2-mod/releases/tag/0.37)

ZIP sadrži Windows x64 DLL, podešavanja, izvorni kod i uputstvo za instalaciju. Verzija 0.37 prošla je sintetičke D3D11 testove. Rad u igri ostaje neproveren.
